# Module 2 notebooks

Hands-on notebooks for Module 2 (see `COURSE_OUTLINE.md` and `../notes.md`).
Recommended order: read the lesson's `notes.md` section, skim the slides, then work
through the matching notebook below.

- `2.1-variables-types-operators.ipynb`
- `2.2-control-flow.ipynb`
- `2.3-data-structures.ipynb`
- `2.4-functions-and-modules.ipynb` (imports the local helper module `greetings.py`)
- `2.5-file-io-and-error-handling.ipynb` (writes exercise files into `scratch/`)
- `2.6-classes-and-objects.ipynb`

`greetings.py` is a tiny helper module used by the 2.4 notebook to demonstrate
importing your own files. `scratch/` holds throwaway files created while running the
2.5 notebook — it isn't course content and can be safely deleted/regenerated.
